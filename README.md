# Who Let the Dogs Out?

My submission for CS50's Introduction to Computer Science – Week 0 (Scratch).

## Description

**Who Let the Dogs Out?** is a short animated Scratch project inspired by the famous song of the same name.

The animation begins with a sleeping guard while a dog quietly enters the scene. After a brief introduction, the music starts and multiple characters begin dancing, creating a playful and entertaining sequence.

Unlike a traditional game, this project is designed as a short animated experience. The viewer simply clicks the green flag and watches the story unfold from beginning to end.

## Inspiration

While looking for ideas in the Scratch community, I found an animation project that demonstrated how music, sprites, and timing could be combined to create an engaging visual experience:

https://scratch.mit.edu/projects/37412/

That project inspired me to create my own animation from scratch. Instead of copying it, I used it as a reference to understand how different elements could work together and then developed my own scene, characters, and sequence of events.

## Features

- Multiple animated sprites
- Costume-based character animation
- Sound and music integration
- Custom blocks for reusable behavior
- Coordinated scene timing
- Animated storytelling

## What I Learned

This was the first project I created entirely on my own using Scratch.

During development, I learned and practiced:

- Event-driven programming
- Sequencing actions over time
- Loops (`repeat` and `forever`)
- Creating and using custom blocks
- Synchronizing multiple sprites
- Working with costumes and animations
- Integrating audio into a project
- Building a simple narrative through programming
