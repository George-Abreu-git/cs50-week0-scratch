# Who Let the Dogs Out?

Projeto desenvolvido para a Week 0 do curso CS50, utilizando Scratch.

## Sobre o Projeto

**Who Let the Dogs Out?** é uma animação curta inspirada na famosa música de mesmo nome.

A ideia foi criar uma sequência divertida utilizando personagens animados, música e diferentes cenários. A animação começa com um guarda dormindo enquanto um cachorro entra em cena. Pouco depois, a música começa e outros personagens aparecem dançando, dando vida à história.

Diferente de um jogo, este projeto foi pensado como uma animação. Basta clicar na bandeira verde e acompanhar a apresentação até o final.

## Inspiração

Durante a busca por referências dentro da comunidade do Scratch, encontrei o seguinte projeto:

https://scratch.mit.edu/projects/37412/

Ele me mostrou como música, animações e sincronização entre personagens poderiam ser combinadas para criar uma experiência divertida. A partir dessa inspiração, desenvolvi minha própria versão, criando novos personagens, cenas e animações.

## Recursos Utilizados

- Múltiplos sprites
- Animações com troca de fantasias
- Efeitos sonoros e música
- Blocos personalizados
- Sincronização entre personagens e cenas
- Construção de uma narrativa simples através de animações

## Aprendizados

Este foi o primeiro projeto que desenvolvi completamente do zero utilizando Scratch.

Durante sua criação, tive contato com conceitos importantes de programação, como:

- Eventos
- Laços de repetição
- Blocos personalizados
- Organização de código
- Sincronização de ações entre sprites
- Animações com fantasias
- Uso de áudio em projetos
- Construção de sequências lógicas

Além dos conceitos técnicos, o projeto também me ajudou a entender melhor como planejar uma ideia e transformá-la em algo funcional e visualmente interessante.

# Who Let the Dogs Out?

My submission for CS50's Introduction to Computer Science – Week 0 (Scratch).

## Description

**Who Let the Dogs Out?** is a short animated Scratch project inspired by the famous song of the same name.

The animation begins with a sleeping guard while a dog quietly enters the scene. After a brief introduction, the music starts and multiple characters begin dancing, creating a playful and entertaining sequence.

Unlike a traditional game, this project is designed as a short animated experience. The viewer simply clicks the green flag and watches the story unfold from beginning to end.

## Inspiration

While looking for ideas in the Scratch community, I found an animation project that demonstrated how music, sprites, and timing could be combined to create an engaging visual experience:

https://scratch.mit.edu/projects/37412/

That project inspired me to create my own animation from scratch. Instead of copying it, I used it as a reference to understand how different elements could work together and then developed my own scene, characters, and sequence of events.

## Features

- Multiple animated sprites
- Costume-based character animation
- Sound and music integration
- Custom blocks for reusable behavior
- Coordinated scene timing
- Animated storytelling

## What I Learned

This was the first project I created entirely on my own using Scratch.

During development, I learned and practiced:

- Event-driven programming
- Sequencing actions over time
- Loops (`repeat` and `forever`)
- Creating and using custom blocks
- Synchronizing multiple sprites
- Working with costumes and animations
- Integrating audio into a project
- Building a simple narrative through programming
